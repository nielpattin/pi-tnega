# Gmail API Reference

Placeholder for future detailed Gmail guidance.

For now, use the shared auth/profile workflow from `../SKILL.md` and direct REST calls to the Gmail API.

Recommended scopes by task:

- Read messages only: `gmail-read`
- Read/modify labels, archive, mark read/unread, and similar mailbox actions: `gmail-modify`

Always enable the Gmail API in the Google Cloud project before calling Gmail endpoints.
